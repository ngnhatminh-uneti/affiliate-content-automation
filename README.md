# Affiliate Studio — Local Affiliate Content Automation

Desktop-first application for turning affiliate products into short-form TikTok/Reels/Shorts videos **without a cloud AI API key**.

## Default architecture

`Product URL → local extraction → Ollama (local LLM) → content variants → Piper Vietnamese TTS → subtitles → Remotion 9:16 → FFmpeg/H.264 → local media library`

TikTok publishing is optional and is the only part that requires a network connection and TikTok OAuth credentials.

## Local stack

- Electron desktop shell
- Next.js 15 + React 19 + TypeScript
- Ollama local HTTP API
- Qwen3 `qwen3:8b` by default (change with `OLLAMA_MODEL`)
- Piper TTS with `vi_VN-vais1000-medium`
- Remotion 4.0.522 + FFmpeg/Chromium
- Local filesystem library/jobs/analytics
- No Gemini API dependency

The project is inspired by [`cyberjalu/video-ai`](https://github.com/cyberjalu/video-ai), but the architecture is redesigned around local-first affiliate production.

## What you can do

- Import a product page or enter product details manually
- Generate 1–10 content variants with different hooks/angles
- Generate Vietnamese narration locally
- Generate timed subtitles automatically
- Render vertical 1080×1920 MP4 locally
- Preview and download finished videos
- Keep product/content/video/job/analytics data on the computer
- Optional TikTok OAuth + Direct Post after explicit confirmation

## Windows setup

Install Node.js 20+ and Git, then from the repository root:

```powershell
npm install
npm run setup:local
npm run desktop:dev
```

`npm run setup:local` installs/configures Ollama, pulls the local Qwen3 model, installs Piper TTS, and downloads the Vietnamese Piper voice model into the app data directory.

You can check the machine with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/doctor.ps1
```

Or launch directly with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

## Desktop production build

```bash
npm install
npm run desktop:build
```

Electron Builder outputs platform installers into `dist/`:

- Windows: NSIS installer
- macOS: DMG
- Linux: AppImage

The local AI models are intentionally downloaded during setup instead of bundled into the installer, keeping the installer smaller and allowing model upgrades without rebuilding the app.

## Configuration

The default local setup needs no API key:

```env
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3:8b
PIPER_MODEL_NAME=vi_VN-vais1000-medium
```

Optional TikTok publishing:

```env
TIKTOK_CLIENT_KEY=
TIKTOK_CLIENT_SECRET=
TIKTOK_REDIRECT_URI=http://127.0.0.1:3210/api/tiktok/callback
```

Never commit real OAuth secrets.

## Data locations

When the packaged desktop app is running, runtime data is stored under the operating system's application-data directory:

- `models/` — Ollama/Piper-related local model files managed by setup
- `media/audio/` — generated narration
- `media/video/` — rendered MP4 files
- `jobs/` — render job metadata
- `library.json` — products and content variants
- `analytics.json` — local pipeline events
- `tiktok.json` — optional TikTok OAuth token data

The app no longer writes generated media into the packaged application directory.

## API surface inside the local app

- `POST /api/products/import` — product extraction
- `POST /api/content/generate` — Ollama content generation
- `POST /api/tts` — Piper narration
- `POST /api/render` — local Remotion render
- `POST /api/batch/generate` — batch content generation
- `POST /api/batch/render` — sequential batch rendering
- `GET /api/jobs` — render history
- `GET|POST /api/library` — local content library
- `GET /api/analytics` — local metrics
- `GET /api/health` — Ollama/Piper readiness
- `/api/tiktok/*` — optional TikTok OAuth/publishing

These routes are served on `127.0.0.1` by the desktop shell; the product is not designed as a public web service.

## Privacy and cost model

The default AI pipeline is local: product text is sent to the Ollama process on the same computer and narration is generated by local Piper. That means no Gemini API key and no per-request cloud AI cost for content generation/TTS.

Network access is still used when you import a public product URL and when you explicitly use online services such as TikTok publishing.

## Production hardening

This is a single-user desktop application. For a multi-user SaaS deployment, replace filesystem persistence with Postgres/Redis/object storage, encrypt OAuth tokens at rest, isolate render workers, and add signed media URLs/authentication.

Review Remotion licensing terms for your commercial deployment model before monetized use.
